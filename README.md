# CIS 4431 – IT Automation
## Lab 11: Enterprise Git & GitHub

### Overview

Welcome to the **IT Automation Lab 11** repository.

This repository contains PowerShell and Bash automation scripts used to demonstrate version control, collaborative development, and code management using Git and GitHub.

Students will practice how enterprise IT teams maintain, update, review, and distribute automation scripts across Windows and Linux environments.

### Learning Objectives

By completing this lab, students will learn how to:

1. Fork a GitHub repository into their own account.
2. Clone a repository using Visual Studio Code.
3. Explore PowerShell and Bash automation scripts.
4. Create and manage Git branches.
5. Modify and personalize existing scripts.
6. Commit changes using Visual Studio Code Source Control.
7. Push changes to GitHub.
8. Create and review pull requests.
9. Understand version history, merging, and collaboration.

### PowerShell Automation (Windows)

**File:** `powershell/system-info.ps1`

This script displays basic Windows system information, including:

- Computer name
- Current username
- Current date and time

**Run in PowerShell:**

```powershell
.\powershell\system-info.ps1
```

Run the command from the repository's root directory in an authorized PowerShell environment. Script execution may depend on the system's execution policy.

### Bash Automation (Linux)

**File:** `bash/system-info.sh`

This script displays Linux system information, including:

- Hostname and username
- Current date and time
- Disk usage
- Memory usage
- Operating system information

**Run in a Linux terminal:**

```bash
bash bash/system-info.sh
```

Run this command from the repository's root directory.

### Student Instructions

Students should follow the detailed instructions provided in **Lab 11 on Canvas**.

The general workflow is:

1. Fork this repository into your GitHub account.
2. Clone your fork using Visual Studio Code.
3. Open and examine the automation scripts.
4. Create a feature branch for your changes.
5. Personalize the scripts as instructed in the lab.
6. Save and commit your changes using Visual Studio Code.
7. Push your feature branch to GitHub.
8. Create a pull request and review the changes.
9. Complete the remaining lab exercises and submit the required files through Canvas.

**Important:** Do not commit passwords, API keys, access tokens, or other sensitive information.
